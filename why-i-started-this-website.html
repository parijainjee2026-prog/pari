Why I Started This Website

This space is my way of learning by doing. It began as an experiment — a place where I could share what I’m curious about, practice building things, and feel more comfortable with the fact that I’m still figuring it out.

When I started, it was just a plain page with a title and some text. Now it’s something I can return to, edit, and make a little bit more me each time. That’s what makes it worth building.

It’s not perfect. It doesn’t need to be. It just needs to be real.

This is the kind of project that reminds me: progress is better than perfection. Every update is a new version of the same idea — one that grows as I do.
