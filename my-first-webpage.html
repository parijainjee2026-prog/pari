My First Webpage

This was the first version of the site I built completely on my own. It felt small at first, but it was the first time I took an idea and turned it into something I could share.

The page was simple: a heading, a few paragraphs, and a lot of trial and error. It taught me how HTML works, how CSS styles text, and how the web is built from the ground up.

It also taught me that the first version doesn't need to be perfect — it just needs to exist. From there, everything can improve.
